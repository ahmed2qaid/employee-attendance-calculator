# Employee Attendance Calculator — Next.js Standalone

نسخة Next.js مستقلة بدون Backend أو Supabase، مع حفظ محلي وتصدير PDF.

## الوظائف
- إدارة عدة موظفين.
- لكل موظف اختيار **وردية واحدة** أو **ورديتين متناوبتين كل 7 أيام**.
- في نظام الورديتين يحدد المستخدم وقت الوردية الأولى، وقت الوردية الثانية، وتاريخ بداية دورة التناوب.
- التناوب يستمر تلقائيًا عبر الشهور والسنوات؛ لا يعتمد على رقم الأسبوع داخل الشهر.
- هذه النسخة وحدها تسمح بتخصيص وقت بداية ونهاية كل وردية لكل موظف.
- سماح التأخير وسماح الانصراف المبكر إعدادان عامان لجميع الموظفين.
- شهر كامل، دورة 26–25، أو فترة مخصصة.
- الجمعة مستثناة تلقائيًا.
- بلا بصمات = غياب، بصمة واحدة = معلق، بصمتان = حضور.
- 8 ساعات = 480 دقيقة = يوم عمل واحد، والحساب الأصلي بالدقائق دون تقريب.
- حفظ Local Storage وتقرير فردي وإجمالي وتصدير PDF عبر الطباعة.

## التناوب الأسبوعي
مثال: إذا كانت بداية الدورة 2026-07-26:
- الأيام 1–7: الوردية 1.
- الأيام 8–14: الوردية 2.
- الأيام 15–21: الوردية 1.
- وهكذا كل 7 أيام.

## التشغيل
```bash
npm install
npm run dev
```

## البناء والنشر
```bash
npm run build
```
الناتج في `out/` ومناسب لـ Netlify أو Vercel.
