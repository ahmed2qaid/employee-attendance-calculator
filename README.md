# نظام حساب دوام الموظفين - Laravel 13

نسخة أولى خفيفة لحساب دوام الموظفين خلال أي فترة زمنية.

## الوظائف
- إضافة الموظفين.
- اختيار موظف + تاريخ بداية + تاريخ نهاية.
- إنشاء جميع الأيام تلقائيًا حتى لو كانت الفترة بين شهرين مختلفين.
- استثناء يوم الجمعة تلقائيًا من الحساب.
- إدخال وقت الحضور والانصراف لكل يوم.
- حساب ساعات ودقائق الحضور الفعلية.
- حساب ما يقابلها من أيام عمل على أساس 8 ساعات = يوم واحد.
- حفظ البيانات وإعادة فتح نفس الفترة لاحقًا.

## تركيب سريع
1. composer create-project laravel/laravel attendance-system
2. انسخ محتويات هذا المجلد داخل المشروع.
3. اضبط قاعدة البيانات في .env.
4. php artisan migrate
5. php artisan serve

## قاعدة الحساب
- الجمعة إجازة ولا تدخل في المجموع.
- دقائق الحضور = الانصراف - الحضور.
- ساعات الحضور = إجمالي الدقائق / 60.
- أيام العمل المكافئة = إجمالي الدقائق / 480.
