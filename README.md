# Employee Attendance Calculator — Next.js + Supabase

نسخة Next.js متصلة بـ Supabase، قابلة للتهيئة لكل مستخدم جديد بدون تعديل الكود.

## التهيئة
1. أنشئ مشروع Supabase جديدًا.
2. شغّل `supabase/schema.sql` في SQL Editor.
3. انسخ `.env.example` إلى `.env.local` وضع URL وAnon Key الخاصين بمشروعك.
4. شغّل `npm install` ثم `npm run dev`.

## سياسة الدوام المرنة
- توجد إعدادات افتراضية عامة للمشروع لسماح التأخير والانصراف المبكر.
- لكل موظف سياسة مستقلة: نوع الوردية + سماح التأخير + سماح الانصراف المبكر.
- يمكن للموظف استخدام القيم الافتراضية أو قيم مخصصة.
- إذا كان التأخير داخل السماح لا يُحتسب. إذا تجاوزه تُحتسب مدة التأخير كاملة من بداية الوردية.
- إذا كان الانصراف المبكر داخل السماح لا يُحتسب. إذا تجاوزه تُحتسب المدة كاملة حتى نهاية الوردية.
- الجمعة مستثناة تلقائيًا.
- بلا دخول وخروج = غياب، وبصمة واحدة = يوم معلق.
- 8 ساعات = 480 دقيقة = يوم عمل واحد، بدون تقريب للحساب الأصلي.

## التخزين
- `app_settings`: الإعدادات الافتراضية العامة.
- `employee_policies`: سياسة كل موظف.
- `attendances`: الدخول والخروج اليومي.

> سياسات RLS المرفقة مفتوحة للتجربة السريعة. أضف Supabase Auth وسياسات مقيدة قبل الإنتاج.
