# Employee Attendance Calculator — Flutter Web + Supabase

نسخة Flutter Web متصلة بـ Supabase مع سياسة دوام مرنة قابلة للتهيئة.

## التهيئة
1. أنشئ مشروع Supabase.
2. شغّل `supabase/schema.sql`.
3. نفّذ `flutter pub get`.
4. شغّل التطبيق عبر `--dart-define=SUPABASE_URL=... --dart-define=SUPABASE_ANON_KEY=...`.

## سياسة الدوام
- إعدادات افتراضية عامة لسماح التأخير والانصراف المبكر.
- سياسة مستقلة لكل موظف: وردية + سماح التأخير + سماح الانصراف المبكر.
- يمكن استبدال سياسة الموظف بالقيم الافتراضية.
- تجاوز السماح يجعل النظام يحتسب كامل مدة التأخير/الانصراف المبكر.
- الجمعة مستثناة تلقائيًا.
- لا بصمات = غياب، بصمة واحدة = معلق، بصمتان = حضور.
- 8 ساعات = 480 دقيقة = يوم عمل واحد.

## Supabase
- `app_settings`: القيم الافتراضية.
- `employee_policies`: إعدادات الموظف.
- `attendances`: سجلات الحضور.

> RLS المرفق مفتوح للتجربة، ويجب تقييده قبل الإنتاج.
