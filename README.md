# Employee Attendance Calculator — Next.js Standalone

نسخة Next.js مستقلة بالكامل بدون Supabase وبدون Backend.

## ماذا تفعل؟
- إدخال اسم الموظف.
- اختيار الوردية: 06:00–14:00 أو 14:00–22:00 أو مرنة.
- اختيار طريقة الفترة:
  - شهر كامل: من 1 إلى آخر يوم في الشهر تلقائيًا.
  - دورة 26–25: مثال اختيار 2026-08 ينتج 2026-07-26 → 2026-08-25.
  - فترة مخصصة.
- اكتشاف الجمعة واستثناؤها تلقائيًا.
- إدخال الحضور والانصراف يومًا بيوم.
- حساب الساعات والدقائق وأيام العمل المكافئة لحظيًا.
- 8 ساعات = يوم عمل واحد.
- حفظ الإدخالات محليًا في Local Storage.
- تصدير التقرير PDF باستخدام نافذة الطباعة/Save as PDF في المتصفح.
- جاهز كناتج Static لـ Netlify أو Vercel.

## التشغيل محليًا
```bash
npm install
npm run dev
```

## البناء
```bash
npm run build
```

بسبب `output: 'export'` سيتم إنشاء الموقع الثابت داخل `out/`.

## Netlify
الفرع يحتوي `netlify.toml` جاهزًا:
- Build command: `npm run build`
- Publish directory: `out`

## Vercel
اربط المستودع واختر branch `nextjs-standalone`. لا توجد متغيرات بيئة مطلوبة.

## ملاحظة البيانات
هذه النسخة لا تشارك البيانات بين الأجهزة؛ الحفظ محلي داخل المتصفح. إذا أردت قاعدة بيانات ومزامنة استخدم branch `nextjs-supabase`.
