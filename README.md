# Employee Attendance Calculator

مستودع واحد يحتوي أربع معماريات مختلفة لنفس نظام حساب دوام الموظفين.

## الفروع
- `nextjs-standalone`: Next.js بدون Backend، حفظ محلي، PDF، مناسب Netlify/Vercel.
- `nextjs-supabase`: Next.js + Supabase.
- `flutter-web-supabase`: Flutter Web + Supabase.
- `laravel-supabase`: Laravel + Supabase PostgreSQL.

## سياسة الدوام الموحدة
- يوم العمل = 8 ساعات = 480 دقيقة.
- الجمعة مستثناة تلقائيًا.
- دعم وردية صباحية 06:00–14:00، مسائية 14:00–22:00، ووردية مرنة حيث تدعمها النسخة.
- سماح التأخير والانصراف المبكر قابلان للتهيئة وليسا ثابتين في الكود.
- توجد قيم افتراضية عامة، مع إمكانية تخصيص السياسة لكل موظف.
- إذا كان التأخير داخل حد السماح فلا يُحتسب، وإذا تجاوزه تُحتسب المدة كاملة من بداية الوردية.
- إذا كان الانصراف المبكر داخل حد السماح فلا يُحتسب، وإذا تجاوزه تُحتسب المدة كاملة حتى نهاية الوردية.
- لا توجد بصمتا دخول وخروج = غياب.
- بصمة واحدة فقط = يوم معلق.
- الحساب بالدقائق دون تقريب، ثم الساعات = الدقائق ÷ 60، وأيام العمل = الدقائق ÷ 480.

اختر الفرع المناسب لبيئة التشغيل التي تريدها واقرأ `README.md` و`SETUP.md` داخل ذلك الفرع.
