# Employee Attendance Calculator — Laravel + Supabase PostgreSQL

نسخة Laravel 13 تستخدم PostgreSQL في Supabase.

## التهيئة
1. انسخ `.env.example` إلى `.env` وضع بيانات PostgreSQL الخاصة بـ Supabase.
2. اضبط السماحات العامة إن رغبت:
   - `ATTENDANCE_DEFAULT_LATE_GRACE=15`
   - `ATTENDANCE_DEFAULT_EARLY_GRACE=5`
3. نفّذ `composer install` ثم `php artisan key:generate` ثم `php artisan migrate`.
4. شغّل `php artisan serve`.

## نظام الورديات
- لكل موظف اختيار وردية واحدة أو ورديتين متناوبتين كل 7 أيام.
- الورديات الجاهزة: صباحي 06:00–14:00 ومسائي 14:00–22:00.
- في حالة الورديتين يُحدد تاريخ بداية الدورة والوردية الأولى والثانية.
- النظام يحسب الوردية الصحيحة من التاريخ نفسه ويستمر التناوب عبر الشهور والسنوات.

## سياسة الدوام
- سماح التأخير وسماح الانصراف المبكر قاعدة عامة لكل الموظفين من إعدادات المشروع.
- لا يوجد سماح خاص بموظف واحد.
- إذا تجاوز الموظف السماح تُحتسب المدة كاملة من بداية/نهاية الوردية.
- الجمعة مستثناة تلقائيًا.
- لا دخول ولا خروج = غياب، بصمة واحدة = معلق، بصمتان = حضور.
- 8 ساعات = 480 دقيقة = يوم عمل واحد.

## Supabase
Supabase هنا هو PostgreSQL فقط؛ Laravel يبقى الـBackend ويحتاج بيئة تشغيل PHP/Laravel.
