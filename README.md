# Employee Attendance Calculator — Next.js + Supabase

نسخة Next.js متصلة بـ Supabase وقابلة للتهيئة لأي مستخدم جديد.

## التهيئة
1. أنشئ مشروع Supabase.
2. شغّل `supabase/schema.sql` في SQL Editor. يمكن إعادة تشغيل الملف لترقية قاعدة قديمة وإضافة حقول التناوب الجديدة.
3. انسخ `.env.example` إلى `.env.local` وأدخل URL وAnon Key.
4. شغّل `npm install` ثم `npm run dev`.

## نظام الورديات
- لكل موظف اختيار وردية واحدة أو ورديتين متناوبتين كل 7 أيام.
- الورديات الجاهزة: صباحي 06:00–14:00 ومسائي 14:00–22:00.
- عند اختيار ورديتين يحدد المستخدم الوردية الأولى والثانية وتاريخ بداية الدورة.
- النظام يحدد الوردية الصحيحة لكل تاريخ تلقائيًا ويستمر عبر الشهور والسنوات.

## السياسة العامة
- سماح التأخير وسماح الانصراف المبكر إعدادان عامان لجميع الموظفين في `app_settings`.
- لا يوجد سماح خاص لكل موظف.
- تجاوز حد السماح يجعل النظام يحتسب كامل مدة التأخير أو الانصراف المبكر.
- الجمعة مستثناة تلقائيًا.
- بلا بصمات = غياب، بصمة واحدة = يوم معلق.
- 8 ساعات = 480 دقيقة = يوم عمل واحد.

## التخزين
- `app_settings`: السماحات العامة.
- `employee_policies`: نظام الورديات لكل موظف وتاريخ بداية التناوب.
- `attendances`: الدخول والخروج اليومي.

> سياسات RLS المرفقة مفتوحة للتجربة السريعة. أضف Supabase Auth وسياسات مقيدة قبل الإنتاج.
